"The Confessional" — a one-line text a smart fridge sends its owner at 3am, on the third visit of the night: the fridge has stopped pretending to be an appliance and started hearing confessions, and the cheesecake already knows. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the text (one line, 124 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
